# Upgrading

Each page covers one release with breaking changes. When skipping several versions, apply the pages in order.

| From | To | Guide |
|------|----|-------|
| 0.x | 1.0 | [ESM migration, named exports](1.0.md) |
| 1.0 / 1.1 | 1.2 | [Consumer scanning, stream-name validation](1.2.md) |
| 1.2 / 1.3 | 1.4 | [Missing streams, string-only `typeAccessor`](1.4.md) |
| 1.4 | 1.5 | [Lazy `Index.range()`, automatic lock recovery](1.5.md) |

All other releases are backwards compatible; see the [Changelog](../changelog.md).

The documentation for a specific release is available through the version selector at the bottom of each page. Version 0.9.1, the last CommonJS release, is kept for comparison.
